# Pokémon Project

A simple Pokémon web project that uses the **PokéAPI** to fetch and display Pokémon information.

## Features

* Search for Pokémon by name
* Fetch Pokémon data from PokéAPI
* Display Pokémon information
* Simple and user-friendly interface
* Uses HTML, CSS, and JavaScript
* API-based dynamic content

## Technologies Used

* HTML5
* CSS3
* JavaScript
* PokéAPI

## API

This project uses **PokéAPI** to get Pokémon data.

## How to Use

1. Open the project in a web browser.
2. Enter a Pokémon name in the search box.
3. Click the search button.
4. The Pokémon information will be displayed.
